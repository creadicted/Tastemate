## Seerr requests

- Admins can link a [Seerr](https://seerr.dev/) server in the Tastemate page (address and API key). The settings are checked against Seerr before they are saved.
- Movies that are not in the library get a **Request in Seerr** button in search results and in your own list, with their Seerr state (requested, downloading, available).
- Requests are made as the user's own Seerr account, matched by Jellyfin user id or user name. Users must have signed in to Seerr with Jellyfin once.

## Also included from 0.5.0

- Optional reason (up to 280 characters) per ranked movie, shown to the other user when you compare.

## Jellyfin Enhanced

- If [Jellyfin Enhanced](https://github.com/n00bcodr/Jellyfin-Enhanced) is installed with its Seerr integration turned on, Tastemate reuses its Seerr address and API key, so there is nothing to set up twice. Settings entered in Tastemate take precedence.
- The Seerr box in the Tastemate page shows where the active settings come from.

## Tastemate for all users

- The Tastemate page is also served at `/Tastemate/Page`, so users who are not administrators can use it. It signs in with the session the Jellyfin web client keeps in the browser.
- If the [File Transformation](https://github.com/IAmParadox27/jellyfin-plugin-file-transformation) plugin is installed, Tastemate adds itself to the web client's user menu, next to Settings. Install File Transformation first and restart Jellyfin. Without it, share the page link instead.
- Admins see a note on the Tastemate page about whether the menu entry is active, with the direct link.
